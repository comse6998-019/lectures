\begin{abstract}
These notes cover the first fifty-minute block of the Week 2 meeting: agent
architectures. We build one patch-generation agent, \msa{}, through five preserved
versions, from a fixed workflow to a reflective attempt loop, and we ask the same question of
each version: which decisions did we make at design time, and which are deferred to the model
at run time? The vocabulary is AIMA's; the mechanisms are those of the assigned papers, quoted
from the versions each section's reading list names. Every section closes with exercises and
the reading it rests on. Listings and traces that
depend on demo code not yet built are marked as stubs naming the artifact expected there. Part~B
turns to the machinery that carries a decision from one step to the next: the record the runtime
keeps, the code that reads it to choose the next node or to stop, and the boundary at which a
requested action becomes an executed one.
\end{abstract}

\begin{abstract}
These notes explain how an agent's runtime connects successive computations. We use extended
state machines to describe state, transitions, and execution traces, then examine how graphs and
events implement those rules. The discussion covers state updates, routing, scheduling, tool
contracts, and execution authority. It also explains how budgets constrain execution and how
controlled measurements support comparisons between implementations.
\end{abstract}

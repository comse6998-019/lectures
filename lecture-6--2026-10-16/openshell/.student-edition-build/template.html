This edition assumes one fact: a process is a running program. Every other term is defined where it first appears.

An agent is a language model joined to a program. The language model, the model for short, chooses each next action and writes it as text. The program carries the action out.

OpenShell is NVIDIA's open-source system for running agents under enforced limits. It runs the agent's program inside a sandbox, an environment that limits what the processes inside it may do.

Each chapter answers one question. It draws the mechanism in the abstract first. It then shows the mechanism at work in Cyberbird, the course's own agent.

The edition describes OpenShell at commit be7af99ff2eacba807d82b69adb0c3d4eaa32158, studied on October 5, 2026. Its facts come from the course's longer guide to OpenShell, written at the same commit. Source links name that commit and a line. Chapter 1 is written, and the contents give the question of every later chapter.

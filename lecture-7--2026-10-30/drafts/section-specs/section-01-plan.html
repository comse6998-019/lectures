Purpose

Give the whole room a shared model of an agent running inside OpenShell, including students who missed Lecture 6. By the end, a student can follow a file request and a model request through the relevant components and explain the distinction between an image, a running sandbox, and a command started inside it.

Starting assumptions for your review

  • Students have met the agent loop and tool dispatcher in earlier lectures.
  • Confirmed: assume minimal background in processes, containers, and operating-system permissions. Introduce the required concepts from first principles.
  • Confirmed: start with Cyberbird immediately and explain each operating-system concept as the agent needs it. The first action or moment to show remains to be settled.
